NiteCore Archives

A private backup utility operated by the owner of the connected Google account.

The utility stores compressed diagnostic files and an accompanying index in the owner's Google Drive. It checks uploaded files before releasing eligible source copies and retrieves selected evidence for owner-directed troubleshooting.

Google access is limited to files created by or explicitly used with this utility. This site contains information about the utility; it does not provide access to the backups.
